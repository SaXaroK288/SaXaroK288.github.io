# Портфолио — инструкция

## Структура
```
index.html          — вся разметка и тексты сайта
style.css            — стили (тёмная тема)
script.js            — подсветка активного раздела в шапке
assets/videos/       — сюда кладёшь видеофайлы .mp4
assets/images/wb/     — сюда кладёшь картинки карточек Wildberries
```

## Как добавить видео (Reels)
Вариант A — файл с компьютера:
1. Положи файл в `assets/videos/`, например `reel-1.mp4`.
2. В `index.html` найди блок `data-slot="reel-1"`.
3. Убери `<!--` и `-->` вокруг строки `<source src="assets/videos/reel-1.mp4" ...>`.
4. Убери класс `is-empty` у тега `<figure class="reel-card is-empty" ...>`.

Вариант B — ссылка на YouTube:
1. В `index.html` найди блок `data-slot="reel-3"`.
2. Убери `<!--` и `-->` вокруг `<iframe ...>`.
3. Вставь в `src` ссылку вида `https://www.youtube.com/embed/ID_ВИДЕО`
   (ID — это то, что после `watch?v=` в обычной ссылке на видео).
4. Убери класс `is-empty` у `<figure>`.

Чтобы добавить ещё карточки — скопируй весь блок `<figure class="reel-card ...">...</figure>`
и вставь ещё раз внутри `<div class="reel-grid">`.

## Как добавить карточки Wildberries
Раздел устроен как несколько "проектов" (`<article class="wb-project">`), у каждого —
своя горизонтальная лента картинок.
1. Положи картинки в `assets/images/wb/`.
2. Чтобы добавить картинку в существующий проект — скопируй строку
   `<img src="assets/images/wb/..." alt="..." loading="lazy">` внутри `.wb-project__strip`
   и поменяй путь и alt-текст.
3. Чтобы добавить новый проект — скопируй весь блок `<article class="wb-project">...</article>`
   и вставь его внутри `<div class="wb-projects">`.

## Как отредактировать текст кейса без видео
В `index.html` найди `id="case"` — там текст про проект по контракту.
Замени плейсхолдерный текст на свой: что делал, какие инструменты, какой результат.

## Как всё это залить на GitHub Pages
1. На странице репозитория `SaXaroK288.github.io` нажми **Add file → Upload files**.
2. Перетащи туда `index.html`, `style.css`, `script.js` и папку `assets` целиком
   (со всеми подпапками и файлами внутри).
3. Внизу нажми **Commit changes**.
4. Через 1–2 минуты сайт появится по адресу `https://saxarok288.github.io`.

Если что-то не отобразилось — обнови страницу с очисткой кэша (Ctrl+F5) и проверь,
что пути к файлам совпадают с названиями (регистр букв важен: `Reel-1.mp4` ≠ `reel-1.mp4`).
